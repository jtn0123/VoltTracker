Connection tools

Proactive adapter checks

Battery voltage looks low. Start the engine before the next test.

Auto-connect
Uses the last adapter and Bluetooth connection events. It does not run Bluetooth discovery.
Notify when adapter is ready
Probes the last-used adapter every 30s and posts a notification when it responds.
Alerts
Battery alerts need notification permission and fire once each time a reading crosses the threshold.
Auto-scan for codes
Runs one background Mode 03 scan shortly after connecting (at most once per drive). New codes feed the diagnostic-code notification above.
